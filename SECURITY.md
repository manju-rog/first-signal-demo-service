# Security scope

This repository is intentionally public because it contains synthetic
demonstration code only. Do not add production source, telemetry, credentials,
customer or account data, internal hostnames, real on-call contacts, or bank
configuration.

The historical code changes are teaching fixtures, not a reusable financial
system and not a statement about any real incident. The repository must never
be connected to a real ledger, payment rail, or customer environment.

For a security issue in the First Signal application itself, use the repository
owner's private GitHub security-reporting channel rather than placing secrets or
sensitive details in a public issue.
